# 🌦️ Weather App

**Weather App** is a simple, modern web app that lets users search for any city and instantly see the current temperature, condition, humidity, and wind speed — with smooth transition animations.

## 📌 About the Project

Weather App provides a clean, glassmorphism-style interface focused on simplicity and a smooth, responsive user experience across different screen sizes.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature display
- ☁️ Weather-condition icons (clear, clouds, rain, snow, mist/haze)
- 💧 Humidity and 💨 wind speed readouts
- ⚠️ "Location not found" state for invalid city names
- ✨ Smooth transition animations when weather data updates
- 📱 Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Boxicons
- Google Fonts – Poppins
- OpenWeatherMap API

## 📱 App Sections

### 🔍 Search Box

Lets the user type a city name and trigger a search with the search icon.

### 🌤️ Weather Display

Shows the current temperature, a matching weather icon, and a short condition description (e.g. "Broken Clouds").

### 💧 Weather Details

Displays humidity percentage and wind speed for the searched city.

### ⚠️ Not Found State

Appears when the entered city name doesn't match any results, showing a friendly "Location not found" message.

## 📱 Responsive Design

The app is responsive and optimized for:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

CSS media queries are used to adapt font sizes, icon sizes, and layout to different screen widths.
